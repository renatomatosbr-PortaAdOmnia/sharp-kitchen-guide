# Sharp Kitchen Guide — presell (reserva 1: faca)

Presell estática para o teste da faca japonesa (ClickBank) com Google Ads. Site separado do de travesseiro e sem a marca do produto no nome, no logo, no cabeçalho ou no rodapé (regra do vendedor).

## Antes de publicar
- [ ] Trocar `MATSATOPRO` pelo vendor id real da ClickBank (aparece no hop link da página de afiliado): `sed -i 's/MATSATOPRO/VENDORREAL/g' index.html`
- [ ] Conferir na página de afiliado se dá para usar fotos oficiais do produto e quais specs (aço, tamanho, garantia) o vendedor autoriza citar
- [ ] Criar repositório `sharp-kitchen-guide` no GitHub e ligar o GitHub Pages (branch main)

## Rastreamento
- `?kw={keyword}&mt={matchtype}` vira `tid` no link da ClickBank (ex.: `bestchefknifee`)
- Clique no link dispara a conversão "Clique na oferta" (AW-18559777099/0f0_CPPCoLMdEMvy_pFF)

## Regras do vendedor
Sem a marca em palavras-chave (inclusive Performance Max), domínio, logo, cabeçalho ou rodapé. Não parecer site oficial.
